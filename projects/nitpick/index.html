Open source · built for agents

The code-review primitive your agent's loop was missing.

nitpick runs specialist reviewers and scanners in parallel sandboxes against a pull request or a branch, puts the findings through a verifier pass, and emits a stable JSON verdict with meaningful exit codes. Wire it into a fix-until-clean loop, a pre-PR polish step, or a CI gate — it never touches your git history.

What's in the box

A review crew with a machine-readable verdict.

Humans get a colour-streamed terminal and a markdown report. Agents get structured JSON and exit codes they can branch on. Same pipeline underneath.

5 specialist reviewers

Security, performance, architecture, testing, and DX — each a focused agent in its own sandbox.

3 automated scanners

Secret detection, linter integration, and dependency checks run alongside the reviewers.

Verifier pass

A second-pass agent re-checks every finding — confirms, adjusts, or rejects — before triage.

Stable JSON contract

Verdict, risk, blockers, accepted findings, and suggested commits — a schema your loop can rely on.

Typed exit codes

Branch on 0, findings, blockers, or changes-requested. No log-scraping.

Never touches git

Read-only against GitHub. No commits, pushes, or history rewrites — the agent applies fixes itself.

Built for agents

Wire it into your agent's loop.

Every invocation is a single atomic step: point at a ref or PR, get JSON back, branch on the exit code. No state between runs.

CI gate

Pre-merge reviewer bot

Runs on every PR push. Posts the verdict and inline comments as a GitHub review, fails CI on changes-requested.

Fix-until-clean

Convergence loop

Agent reads verdict.blockers, edits each filePath:lineStart per recommendation, commits, retries until clean.

Pre-PR polish

One-pass cleanup

Before opening a PR: run once, apply high-severity recommendations, commit grouped fixes via suggestedCommits, push.

Safety rails — what nitpick intentionally won't do:
  • No git push, commit, branch creation, or history rewrites.
  • No network calls beyond GitHub (read-only) and the sandbox.
  • No persistence of findings between runs — every invocation is stateless.

Install

Up and running in a minute.

Requires Node.js and an Upstash Box account for sandboxing. GitHub token falls back to gh auth token if unset.

Install
# clone & install
git clone https://github.com/ilterkavlak/nitpick.git
cd nitpick && pnpm install
cp .env.example .env

# install the nitpick binary globally
pnpm pack
pnpm add -g ./nitpick-*.tgz

# verify
nitpick --help
Usage
# interactive — browse repos, pick a PR
nitpick

# one-shot review of a pull request
nitpick review https://github.com/org/repo/pull/42

# review a branch without an open PR
nitpick review --repo org/repo --base main --head feature/xyz

# agent / CI — JSON on stdout, exit code as the signal
nitpick review --repo org/repo --base main --head feature \
  --auto --non-interactive --json - --exit-on blockers
