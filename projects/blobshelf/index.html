Open source · native macOS app

Your Upstash Blob buckets, as a drive on your Mac.

Blobshelf is a small native macOS app for Upstash Blob. Browse your buckets like folders in Finder, and keep folders on your Mac backed up to them automatically — much like Google Drive for desktop. It runs in Apple's App Sandbox with the smallest set of permissions it can work with, and you build it yourself from source.

Features

A Finder for your buckets, and backups that never delete.

🗂️

Browse

Any number of buckets in a list or grid: folders, upload (button or drag and drop, folders included), download, Quick Look, rename, delete, new folder, search, and copyable links for public buckets.

🔁

Automatic backups

Pick a folder and a bucket. New and changed files upload a few seconds after they change, on a schedule, and on Back Up Now. Backups only add and update — deleting a file on your Mac never deletes it from the bucket.

📶

Menu bar status

The icon shows whether everything is backed up, syncing, paused or needs attention; its panel lists every backup and transfer with progress. Keeps running when you close the window.

⚡

Fast

Large files upload in parallel parts, backups upload eight files at a time, and only new or changed files are sent.

Security at a glance

Four permissions. Two hosts. No third-party code.

Everything the app may do is in Support/Blobshelf.entitlements, and CI checks it is exactly these four.

🔒

Sandboxed

App Sandbox plus the hardened runtime, with only four entitlements.

📁

Only what you pick

Sees only files and folders you choose. Backup folders are opened read-only.

🔑

Keychain tokens

Bucket tokens live in your Keychain — never in files or logs.

🌐

Two hosts, HTTPS

blob.upstash.io and Cloudflare R2. No analytics, tracking or update checks; nothing cached on disk; redirects refused.

🚫

Safe defaults

Refuses to back up into public buckets and skips secrets such as SSH keys, .env files and cloud credentials.

🛡️

Never runs bucket code

Apps, scripts and installers are only previewed, and every download is quarantined so macOS checks it first.

PermissionWhy
App SandboxWalls the app off from the rest of your Mac.
Outgoing networkReach blob.upstash.io and your bucket's storage. Nothing can connect to the app.
Files you chooseOnly what you pick or drop on the window. Write access only to save downloads where you chose.
Remember foldersSo backups can read their folders after a restart — remembered read-only.
What leaves your MacSent to
Bucket tokenblob.upstash.io, exchanged for storage credentials that expire after about 10 minutes.
Files you upload or back upYour bucket on Cloudflare R2, with their names and folder paths.
Anything elseNothing: no usage data, no device name, no file listings beyond what you back up.

Data is encrypted in transit and stored encrypted by the provider, but it is not end-to-end encrypted: Upstash and Cloudflare, as operators of the storage, could read it. Anyone with a bucket's token can read and change everything in that bucket.

Build & install

You build it yourself. It takes about a minute.

macOS 14 (Sonoma) or newer, on Apple silicon or Intel. Because you build it on your own Mac, there is no "unidentified developer" warning.

Terminal
# Command Line Tools (skip if you have Xcode)
xcode-select --install

# get the code, then build and install
git clone https://github.com/ilterkavlak/blobshelf.git
cd blobshelf
./install.sh

Installs to /Applications (or ~/Applications) and opens. To update later: git pull && ./install.sh. To remove everything: ./uninstall.sh — it asks first and never touches your buckets.

  1. Add a bucket

    Click Add Your First Bucket and paste its token from the Upstash console. Add as many as you like.

  2. Browse

    Choose a bucket in the sidebar. Drop files onto the window to upload them.

  3. Back up a folder

    Backups → Add Backup: pick a folder, a private bucket and a destination. Exclude patterns are shell globs like .git or *.tmp.

  4. Keep it running

    Optional: Settings → Open at login, so backups survive a restart.

How this was built

Vibe coded — and upfront about it.

Claude (in Claude Code) wrote the code from a description; OpenAI's Codex reviewed the plans and the code over several rounds, and an independent AI security audit was run. No human has reviewed it line by line. What is verified:

  • 64 automated tests, including live tests against a real Upstash Blob bucket: multipart uploads, unusual file names, 1,000+ objects, credential refresh, and incremental backups that skip secrets and never delete.
  • CI builds the app, runs the tests, and checks the entitlements are exactly the four above.
  • The packaged app launches sandboxed with those entitlements.

Not verified: a human security audit, or UI tests. It is about 3,000 lines of Swift with no dependencies — read it before trusting it with data that matters. Blobshelf is an independent project, not an official Upstash product.
